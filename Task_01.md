### Условие

Дан бинарный файл, состоящий из последовательности 32-разрядных беззнаковых целых чисел в формате **big-endian**. Размер файла — от 2 ГБ и выше.

Необходимо написать программу `calc_data.py`, которая:

- вычисляет **сумму** всех чисел (с применением длинной арифметики — результат может не влезать в 64 бита)
- находит **минимальное** и **максимальное** число
- выводит результат в stdout в формате:

```
sum=<число>
min=<число>
max=<число>
```

Программа должна запускаеться командой:

```bash
python3 calc_data.py <path_to_file>
```

Условия:
1. Результат должен совпадать с эталоном. Неверный ответ даёт 0 баллов вне зависимости от скорости.
2. Баллы начисляются в зависимости от времени работы на тестовых файлах. Чем быстрее, тем больше баллов (зависит от других результатов).
3. Программа  запускаться внутри Docker-контейнера. 
4. Число доступных ядер заранее неизвестно. 

Сборка контейнера будет происходить как-то так:
```bash
docker build -t calc_data .
docker run --rm -v /path/to/data:/data:ro calc_data /data/input.bin
```

В репозитории должен быть как минимум Dockerfile и `calc_data.py`. Должен использоваться базовый образ на основе `python:3.14-slim`.

Пример:

```dockerfile
FROM python:3.14-slim

RUN apt-get update && apt-get install -y --no-install-recommends \
    gcc \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app


# COPY requirements.txt .
# RUN pip install --no-cache-dir -r requirements.txt

COPY calc_data.py .

ENTRYPOINT ["python3", "calc_data.py"]
```
